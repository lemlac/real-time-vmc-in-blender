# real-time-vmc-in-blender
Add-on for Blender that controls a 3D model in real time with the VMC protocol

## Instructions to Install and Run the Boilerplate Add-on

1. Save the File: Download `open_vtube_addon.py` file.
2. Install in Blender:
  * Open Blender and go to **Edit > Preferences > Add-ons**.
    * Click **"Install..."** at the top right and select the downloaded `open_vtube_addon.py` script.
    * Check the checkbox next to **"Animation: OpenVTube Boilerplate"** to activate it.
3. Run the Streaming Receiver:
  * In your 3D Viewport, press **N** to open the sidebar.
    * Select the OpenVTube tab.
    * Choose your desired network port (Default: 39539 for standard VMC pipelines) and click **Start Receiver**.
